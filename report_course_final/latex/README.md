
# 一条通道上的两支队伍

中山大学《无人系统导论》课程设计，题目二。基线为作者指定的 47 页 XeLaTeX 报告，已纳入 2026 年 11 月 20 日 AMAX 补验。

## 编译

将 ZIP 上传到 Overleaf，新建项目后选用 **XeLaTeX**，主文件为 **main.tex**。目录和引用由 LaTeX 自动更新。工程已预置正文所需的 16 幅 PDF 图，编译时直接读取这些图。

- `main.tex` 负责纸张、字体、页眉、目录与编号。
- `cover.tex` 是封面，原色校徽背景位于 `assets/cover-background.png`。正文和附录位于 `chapters/`。
- `references.bib` 保存原报告参考文献，`ref-order.tex` 保持编号顺序。
- `figures/` 为正文使用的彩色图和原色仿真截图。原图和重绘脚本位于 `figure_sources/`，供核对图表来源。

## 表达与版式

全文围绕设计动机、工作原理、实验对照和结论范围组织。正文用实验对象和观察结果解释方法，复查入口集中在附录 A，具体失效现象与复验集中在附录 C。章节顺序、八实体任务分工、十四项任务、共享通道机制和原有实验条件均按底稿。原稿中 W、E 航点与早期占用窗口的关系按给定坐标修正。

正文保留黑白排版，图表用低饱和配色辅助比较。表格为三线表，较长的表格跨页重复表头。图中的分组通过可辨识的线型、标记或纹理呈现。图、表、公式与引用可在源码中交叉跳转。
