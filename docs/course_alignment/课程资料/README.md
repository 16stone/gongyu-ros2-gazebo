## 二、课程全局框架（第一讲 slide4–9）

- **课程总目标**：介绍陆、海、空、天无人系统的基本知识、基本原理及发展概况，掌握设计方法与应用开发，理解关键技术交叉融合。
- **课程考核**：考勤 10% + 课后作业 30% + 课程报告 60%（第一讲 slide8）。
- **课程要求层次**：一般了解发展概况；了解熟悉常见建模与仿真工具；一般掌握系统组成与自主技术；**牢固掌握探测、导航制导与控制系统设计基础**（第一讲 slide7）。
- **7 大知识模块**（第一讲 slide9 展开）：基本概念内涵 / 任务使命及运用 / 发展现状及趋势 / 社会学问题 / 总体设计技术 / 导航制导与控制 / 任务载荷与数据链。
